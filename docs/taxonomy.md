# Diagram taxonomy

Counts are for the full reviewed private library snapshot of 11 November 2026. The public [recent-1000 catalog](../catalog/recent-1000.json) is a curated subset, so its category totals differ.

## First-page Intro

26 compact opening diagrams from the first page, stored as a separate collection. This is a placement-and-layout collection, not an assertion that every crop is exactly half a column in the publisher typesetting. The underlying page and crop width should be checked before copying a layout.

## Concept & comparison

199 diagrams explaining a problem, replacing an older structure, or contrasting two designs. This is catalog category `intro`.

## Frameworks

619 diagrams showing the complete model or processing workflow. This is category `framework`.

## Module details

287 diagrams expanding a local component such as attention, fusion, an encoder block, or conditioning path. This is category `detail`.

These four groups are exclusive in the current snapshot. Future metadata may add orthogonal tags for page placement, model family, and visual pattern without double-counting figures.
