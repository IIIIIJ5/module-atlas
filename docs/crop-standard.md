# Diagram-only crop standard

1. Work from the publisher image or official/author PDF, not a web screenshot.
2. Keep the complete diagram and all semantic arrows, labels, and legend items.
3. Remove figure captions, running text, page headers/footers, and unrelated result panels.
4. If a multipart figure has only one structural subpanel, crop that subpanel and record it precisely.
5. Inspect the full-resolution export after cropping; reject clipped branches and unreadable labels.
6. Retain the original figure number, page, source URL, crop coordinates, and checksum.
7. Track image quality separately from redistribution rights.

PDF-based crops can retain native vectors. Publisher-hosted raster images retain their native source resolution; upscaling does not create new detail.
